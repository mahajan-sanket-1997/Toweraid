# TowerAid

Flutter MVP for emergency response in residential buildings.

## MVP
- Resident, Security and Admin roles
- One-tap emergency flow
- Fire, medical, lift, gas leak and accident types
- I'm Safe / I Need Help
- Tower/floor/flat security dashboard
- Resident emergency contacts
- Admin overview

## Run
```bash
flutter pub get
flutter run
```

This MVP uses local demo state. Production should add Supabase Auth/Postgres/RLS/Realtime and FCM push notifications.
